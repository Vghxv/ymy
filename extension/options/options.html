A full path, for example D:\Music\YouTube. It is created if it doesn't exist. Leave empty to use the default.

Before turning this on: a check searches the download folder and every subfolder for the track.
  • Network folders: if the download folder is on another computer (\\server\share or a mapped network drive), Windows connects to that computer on every check and sends it your Windows sign-in details (a password hash), which someone running that computer could try to crack. Only use a network folder you trust.
  • Large folders: searching a big folder, or a whole drive like C:\, can take minutes and keeps the disk busy. Use a folder that holds only your music.
With this off, nothing is searched until you click Check folder in the popup.

When there is one, a notification and the popup offer to update it in one click.
